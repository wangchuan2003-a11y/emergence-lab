# Product

## Purpose and platform

Emergence Lab is a browser-based laboratory for visually exploring local rules and emergent patterns. It serves curious visitors, learners and GitHub reviewers. It is a static TypeScript/Canvas 2D/Vite application deployed with GitHub Pages; no account, backend or runtime AI API is required.

## Current capabilities

- Six modes: flocking, orbital flow, vector field, Gray–Scott coral/cell-like patterns and a Physarum-inspired trail network.
- Direct parameter control, seeded initialization, pause/resume, single stepping, center perturbation and touch/mouse brushes.
- Eight-state undo/redo for explicit brush and center edits; changing settings/scenes starts a new editing context.
- Three model-derived scene recipes, prepared in cancellable chunks and applied only when complete.
- Chinese/English UI, canvas-scoped keyboard shortcuts, reduced-motion startup and responsive controls.
- Settings links for initial configurations; validated JSON snapshots for exact numerical checkpoints, including current edited fields.
- Screen or high-resolution PNGs, bounded browser-native video capture and a version-consistent offline shell.
- A build revision link that identifies the actually loaded application bundle.

## Evidence and scope

All displayed patterns come from the implemented models. Preview assets are generated by checked-in scripts. Numerical, state, cancellation and UI contracts are exercised by automated tests; CI publishes only after its build/test stages pass. See docs/verification.md and docs/iterations.md for concrete runs and remaining boundaries.

The chemical fields are not coral tissues or real cell division. The trail model does not claim biological accuracy, intelligence or shortest-path optimality. Source/model differences are documented in docs/references.md. More PNG pixels do not add simulation resolution. Cross-platform numerical trajectories may differ slightly.

User files are parsed locally and are not uploaded. Offline caches contain only the scoped static build, not imported experiments. No private knowledge-vault material is part of this repository.
